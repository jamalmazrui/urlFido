urlFido Hotkeys

The keys of the urlFido dialog, listed three ways. Each Alt key is the letter underlined in its control’s label, so a screen reader reads it with the control, and each matches the control’s command-line switch where it has one: -e and Alt+E reach the same setting. OK and Cancel have no letter: Enter is OK and Escape is Cancel.

By key

  • Alt+A — Authenticate credentials
  • Alt+B — Browse source
  • Alt+C — Choose output
  • Alt+Control+U — open the urlFido dialog from anywhere (the desktop shortcut)
  • Alt+D — Default settings
  • Alt+E — File extensions
  • Alt+F — Force overwrite
  • Alt+H — Help
  • Alt+I — Invisible browser
  • Alt+L — Log session
  • Alt+M — Main profile
  • Alt+O — Output directory
  • Alt+S — Source urls
  • Alt+T — Test fetch
  • Alt+U — Use configuration
  • Alt+V — View output
  • Control+Enter — OK, from any control
  • Enter — OK: start the run
  • Escape — Cancel: close without running
  • F1 — Help
  • F11 — check for a newer version
  • Shift+F1 — say the focus tip for the current field

By command

  • Authenticate credentials — Alt+A
  • Browse source — Alt+B
  • Cancel — Escape
  • Check for a newer version — F11
  • Choose output — Alt+C
  • Default settings — Alt+D

  • Force overwrite — Alt+F
  • Help — Alt+H or F1
  • Invisible browser — Alt+I
  • Log session — Alt+L
  • Main profile — Alt+M
  • OK — Enter, or Control+Enter from any control
  • Open the dialog from anywhere — Alt+Control+U
  • Output directory — Alt+O
  • Say the focus tip — Shift+F1
  • Source urls — Alt+S
  • Test fetch — Alt+T

The text-field editing keys every Lbc dialog offers are listed in the guide under Dialog Editing Keys.

Why these keys

F1 is help in every Windows program. F11 is the Homer key for updating a program to its newest release, because “elevate” sounds like “eleven”. Alt+Control+U belongs to the desktop shortcut; Alt+Control keys are for desktop shortcuts, and U is the first letter of urlFido’s url. urlCheck, the companion tool, uses Alt+Control+Shift+U, so the two never contend for one key.
