# urlFido 1.2.0

urlFido downloads files of the types you choose from web pages, driving your installed Microsoft Edge so pages behave as they do for a person at the browser. Get it from the [urlFido releases page](https://github.com/JamalMazrui/urlFido/releases).

## What is new in 1.2.0

- **Update from inside the program.** Press F11 in the dialog to check GitHub for a newer version. If there is one, Enter downloads and starts its installer.
- **A log of every session.** Each run keeps its own log in `%LOCALAPPDATA%\urlFido\logs`, so a problem can be explained afterwards even when Log session was off.
- **Settings in the Homer place.** Use configuration now saves to `%LOCALAPPDATA%\urlFido\configs\urlFido.inix`. Settings from earlier versions are carried over.
- **A tidier installation.** The program is in the `exec` folder and the documents in `help`, as in every Homer Tools program. The installer's results box comes before urlFido starts.
- **Alt+Control+U is urlFido's alone.** urlCheck now uses Alt+Control+Shift+U.

The full list of changes is in History.

## About the companion accessibility tools

urlFido, urlCheck, extCheck and 2htm are a small family of free, MIT-licensed Windows tools written by Jamal Mazrui and shared on GitHub. They share control names, dialog layout and command-line spellings wherever the idea is the same.

- [urlFido](https://github.com/JamalMazrui/urlFido) — downloads files from web pages by extension.
- [urlCheck](https://github.com/JamalMazrui/urlCheck) — checks web pages with Edge and axe-core and writes a draft Accessibility Conformance Report.
- [extCheck](https://github.com/JamalMazrui/extCheck) — checks the accessibility of `.docx`, `.xlsx`, `.pptx` and `.md` files.
- [2htm](https://github.com/JamalMazrui/2htm) — converts Office documents and other formats to clean, accessible HTML.
