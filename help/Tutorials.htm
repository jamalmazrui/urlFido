0 - Overview

What urlFido is, how it fetches, and the ten walks that teach it.

Before you start: Nothing to set up; this walk only listens.

Step 1

Welcome. This is the first of ten short walks through urlFido. I am the host; the other voice is the screen reader, speaking as it would on your own computer.

Step 2: Insert+Up Arrow

Two reader keys help in every walk. If a line goes by too fast, Insert plus Up Arrow says it again.

Screen reader:

  • Source urls edit

Confirm the wording with a live run: buildTutorials -live.

Step 3: Insert+Tab

And whenever you are unsure where you are, Insert plus Tab says what has the focus.

Screen reader:

  • Source urls edit, blank

Confirm the wording with a live run: buildTutorials -live.

Step 4

urlFido downloads the files a web page links to, of the kinds you choose: PDF documents, Word documents, zip archives, or any other extension you name.

Step 5

Unlike a plain downloader, it opens each page in Microsoft Edge, so the page behaves as it would for you: scripts run, cookies apply, and links that appear only after loading are found.

Step 6

It saves each page’s files into a folder named after the page’s title, so a run over several pages stays easy to tell apart.

Step 7

It can try first, with Test fetch, saying what it would download without downloading anything.

Step 8

It runs from a dialog opened from the desktop, or from the command line, where one line can fetch from a whole list of pages.

Step 9

Here are the walks. One, the dialog. Two, installing. Three, a page’s documents. Four, choosing what to fetch. Five, trying first with Test fetch.

Step 10

Six, several pages at once. Seven, pages behind a sign in. Eight, the command line. Nine, the conclusion, a glossary, and where to get help.

Step 11

Each walk is a few minutes long and builds on the last. Walk one comes next.

Something to try: Think of a web page with documents you want to keep. Walk three fetches them.

4 - Choose What to Fetch

The File extensions field: short forms, full patterns with wildcards, and matching on a part of the name.

Before you start: urlFido installed, and a page with several kinds of file.

Step 1

One want: just the files I need from a page that links to dozens, such as only the Word templates, or only one edition.

Step 2: Alt+E

File extensions takes a list, separated by commas or spaces. Each entry is a pattern, in the style of the Windows command prompt.

Screen reader:

  • File extensions edit, docx pdf zip

Confirm the wording with a live run: buildTutorials -live.

Step 3

The short forms are shorthand: pdf means dot pdf, which means star dot pdf, any name ending in dot pdf.

Step 4

So the familiar pdf, docx still works exactly as it always has.

Step 5

To take only the Word templates, I replace the list with docx alone.

Screen reader:

  • docx

Confirm the wording with a live run: buildTutorials -live.

Step 6: Enter

Enter, and only the Word files come.

Screen reader:

  • 3 files downloaded

Confirm the wording with a live run: buildTutorials -live.

Step 7

A pattern can be more specific: star WCAG star dot docx takes only Word files whose names mention WCAG.

Screen reader:

  • star WCAG star dot docx

Confirm the wording with a live run: buildTutorials -live.

Step 8: Enter

Enter, and only that edition comes.

Screen reader:

  • 1 file downloaded

Confirm the wording with a live run: buildTutorials -live.

Step 9

The match is on the file’s own name, the one the site supplies, so it works even when the link’s text says something else.

Step 10

A question mark stands for any one character, as at the command prompt, for names that differ by a single letter or digit.

Step 11

Several patterns can share the list: star dot pdf and star dot epub together take both kinds.

Step 12

Matching ignores case, so star newsletter star dot PDF and star newsletter star dot pdf behave the same.

Step 13

What counts as a file is a link whose target has an extension, or one the server announces as a download; ordinary links to pages are left alone.

Step 14: Alt+U

Use configuration remembers the list, so a pattern worked out once is ready the next time.

Screen reader:

  • Use configuration check box, checked

Confirm the wording with a live run: buildTutorials -live.

Step 15

A precise pattern saves time and space, and keeps a folder to just the documents that matter.

Step 16

A pattern like star newsletter star takes every file whose name contains newsletter, whatever its kind.

Step 17

A Test fetch, walk five, is the quickest way to check a new pattern against a real page.

Step 18

Short forms and patterns can be mixed in one list: pdf, star report star dot xlsx.

Step 19

Several patterns can name the same kind of file in different ways; a file that matches any one of them is fetched once.

Step 20

A wide pattern is cheap to try with Test fetch, and a narrow one saves a folder of unwanted files.

Step 21

The patterns you settle on for a site are worth keeping in a note beside its source list, for the next time.

Step 22

Short forms for the usual, patterns for the precise. The next walk tries a run before making it.

Something to try: Fetch only the Word editions from the VPAT page, then only the edition for WCAG.
